How the code CNRB0005667 is built

CNRB is the bank part: the letters of Canara Bank. The fifth character is always the digit 0. 005667 is the part that names this branch.

The MICR code 500015079 is the number printed along the bottom of this branch's cheques. 500 is the city (the same three digits that begin the PIN code 500011), 015 is the bank and 079 is the branch.
