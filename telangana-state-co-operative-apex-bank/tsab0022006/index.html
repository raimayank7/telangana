How the code TSAB0022006 is built

TSAB is the bank part: the letters of Telangana State Co-operative Apex Bank. The fifth character is always the digit 0. 022006 is the part that names this branch.

The MICR code 507809502 is the number printed along the bottom of this branch's cheques. 507 is the city (the same three digits that begin the PIN code 507203), 809 is the bank and 502 is the branch.
