How the code SBIN0022095 is built

SBIN is the bank part: the letters of State Bank of India. The fifth character is always the digit 0. 022095 is the part that names this branch.

The MICR code 503002688 is the number printed along the bottom of this branch's cheques. 503 is the city (the same three digits that begin the PIN code 503225), 002 is the bank and 688 is the branch.
