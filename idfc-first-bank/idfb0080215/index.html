How the code IDFB0080215 is built

IDFB is the bank part: the letters of IDFC FIRST Bank. The fifth character is always the digit 0. 080215 is the part that names this branch.

The MICR code 500751011 is the number printed along the bottom of this branch's cheques. 500 is the city (the same three digits that begin the PIN code 500072), 751 is the bank and 011 is the branch.
