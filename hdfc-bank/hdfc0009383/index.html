How the code HDFC0009383 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 009383 is the part that names this branch.

The MICR code 500240111 is the number printed along the bottom of this branch's cheques. 500 is the city (the same three digits that begin the PIN code 500008), 240 is the bank and 111 is the branch.
